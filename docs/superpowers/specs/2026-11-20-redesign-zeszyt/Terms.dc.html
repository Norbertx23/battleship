Regulamin

Obowiązuje od 20 listopada 2026 r.

This document is available in Polish only, as the game is run from Poland. In short: play fair, nicknames aren't moderated and are your own responsibility, the game is provided as is with no guarantees, and you can report problems via GitHub Issues.

1. Kilka słów na start

  1. Regulamin określa zasady korzystania z gry przeglądarkowej Battleship (dalej: „Gra”), dostępnej pod adresem https://battleship.swistak.fun/.
  2. Grę prowadzi hobbystycznie Norbert Świstak (dalej: „Autor”), kontakt: swistak.fun@gmail.com lub GitHub Issues.
  3. Gra jest bezpłatna, nie wymaga zakładania konta i nie zawiera reklam ani płatności.
  4. Kod źródłowy Gry jest otwarty i udostępniony na licencji MIT w serwisie GitHub.

2. Czego potrzebujesz

  1. Urządzenia z dostępem do internetu i aktualnej przeglądarki (Chrome, Firefox, Safari lub Edge) z włączonym JavaScriptem.
  2. Rozpoczęcie gry oznacza akceptację Regulaminu. Możesz przestać korzystać z Gry w każdej chwili, po prostu zamykając stronę.

3. Zasady korzystania

  1. Graj uczciwie i z szacunkiem dla innych graczy.
  2. Zabronione jest używanie nicków wulgarnych, obraźliwych, nawołujących do nienawiści, podszywających się pod inne osoby lub zawierających cudze dane osobowe.
  3. Zabronione jest zakłócanie działania Gry, w szczególności ataki na serwer, automatyczne skrypty (boty) oraz wykorzystywanie błędów do uzyskania przewagi.
  4. Gra jest przeznaczona do prywatnej rozrywki.

4. Nicki

  1. Nick jest widoczny publicznie w historii meczów i rankingu.
  2. Nicki nie są filtrowane ani moderowane. Za wybrany nick odpowiada wyłącznie gracz, który go wpisał.
  3. Jeśli uważasz, że jakiś nick narusza prawo lub Twoje prawa (np. zawiera Twoje dane), poproś o jego usunięcie przez GitHub Issues. Nie podawaj w zgłoszeniu danych osobowych, bo zgłoszenia są publiczne.
  4. Autor może usunąć nick naruszający Regulamin wraz z powiązanymi wpisami.

5. Odpowiedzialność

  1. Gra jest udostępniana bezpłatnie, w stanie „takim, jaki jest”, bez gwarancji, że będzie działać nieprzerwanie, bezbłędnie lub bez utraty danych, w tym wyników i historii meczów.
  2. Autor może w każdej chwili przerwać działanie Gry, zmienić ją lub całkowicie zakończyć jej udostępnianie, bez obowiązku zachowania wyników.
  3. Autor nie odpowiada za treści wpisane przez graczy, w tym za nicki, ani za skutki ich użycia. Treść, o której bezprawności Autor otrzyma wiarygodną informację, zostanie niezwłocznie usunięta.
  4. Autor nie odpowiada za przerwy w działaniu wynikające z przyczyn od niego niezależnych, w tym awarii hostingu, sieci lub urządzenia gracza.
  5. W zakresie dopuszczalnym przez prawo odpowiedzialność Autora jest wyłączona. Postanowienia tego punktu nie ograniczają odpowiedzialności za szkodę wyrządzoną umyślnie ani praw przysługujących konsumentom na podstawie bezwzględnie obowiązujących przepisów.

6. Reklamacje i zgłoszenia

  1. Problemy z działaniem Gry oraz reklamacje zgłaszaj przez GitHub Issues lub na adres swistak.fun@gmail.com.
  2. Opisz problem. Odpowiemy w ciągu 14 dni.

7. Postanowienia końcowe

  1. Zasady przetwarzania danych opisuje Polityka prywatności.
  2. Autor może zmienić Regulamin. Nowa wersja obowiązuje od daty opublikowania na tej stronie.
  3. W sprawach nieuregulowanych stosuje się prawo polskie, w szczególności ustawę o świadczeniu usług drogą elektroniczną i Kodeks cywilny.
